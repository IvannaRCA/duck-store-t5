### Descripción
Creación de una página web de una tienda de patitos (DuckStore) en HTML5 y CSS.

### Herramientas
- Git
- GitHub
- Visual Studio Code
- Figma
- Stitch
- Jira
- Obsidian

### Planificación y normas
Estructura de carpetas del proyecto:
- assets -> images
- css
- pages

Nomenclatura de archivos en kebab-case:
- nombre-archivo.extension

Metodología:
- SCRUM con Jira
